# Griggs-International-Academy-HS
High School
# 📖 Sobre o Projeto
O projeto **Griggs International Academy HS** foi desenvolvido com o objetivo de representar e organizar aspectos da High School da Griggs International Academy, reunindo informações acadêmicas, organização escolar e recursos voltados ao ambiente estudantil.

# 🎯 Objetivo
Desenvolver uma plataforma/projeto voltado para o ambiente da High School, promovendo organização, acessibilidade e centralização de informações importantes para estudantes e equipe acadêmica.
